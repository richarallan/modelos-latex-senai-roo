# Prompt curto para uma IA

Copie o texto abaixo e acrescente o assunto, a finalidade e os dados reais que
podem ser usados. Entregue também um dos
[Markdown iniciais](README.md#comece-por-um-markdown) e os
[exemplos de elementos](elementos.md).

```text
Produza um Markdown compatível com o núcleo documental deste repositório.
Use o arquivo inicial fornecido, preserve os campos obrigatórios e os tipos
documentais existentes. Escreva parágrafos, títulos e listas em Markdown comum.
Use blocos semânticos e propriedades chave-valor somente conforme os exemplos:
identificador, titulo, arquivo, fonte, nota e idioma. IDs devem ser únicos e
estáveis; não escreva números de figuras, tabelas, gráficos ou equações à mão.
Use referências bibliográficas reais com IDs cadastrados e cite-as no texto.
Não invente pessoas, contatos, assinaturas, aprovações, fontes ou resultados.
Omita campos opcionais desconhecidos. Informe separadamente o que falta para
concluir o conteúdo; não coloque avisos de preenchimento no PDF final.
Retorne o Markdown e a lista dos arquivos de apoio usados.
```
